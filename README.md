# Project1_ReadingHouse
By: Ammaela Khan

1. A brief plan and a wireframe

This application is for adding in a reading list of all the book you want to read and then be able to add a review (description) for that book as well. It will follow the idea of having a “To Do List or Task List” but it will be a reading list for all book lovers! So they can keep tracks of all the books they have read and also good back and read their review of it. 

2. Planned Features:

   - Ability to add books “to be read.”
   - Then also add a description (review) for the book.
   - Be able to cross of that book when done and it goes in to the “books read” section.
    - Able to delete or edit the added information.
    - Maybe have different sections like Reading, To Be Read, Read.

6. Describe the technologies you used and their role in your project.

    HTML – page structure
    CSS – styling and layout
    JavaScript – functionality, DOM scripting and form validation
    localStorage – saving data in the browser

7. How to use the application
   
    - Open the published application using the link above.
    - You add a book title and author to add it to you "To Be Read List" or "tbr."
    - Then you can either delete the item or click start reading and that will move it to your reading page.
    - Once you have completed the book you can move it to the "read" list simply by checking it off!
    - You can refresh the page and check whether data remains available in the browser, and it should! 

9. Running the application locally

    Clone or download this repository to your computer.
    Open the project folder.
    Open index.html in a web browser.
